Heliolisk - Portfolio WordPress Theme for Analysts, Operators & Creators

Latest Update: 11 October, 2026 · Version 1.2.0

  • Dark and Light color schemes - switch with one click
  • Built with Elementor: 13 custom Heliolisk widgets
  • Projects custom post type with categories and tags
  • Header and Footer builder - set site-wide or per page
  • Theme Options panel (Codestar Framework) plus Customizer support
  • Blog with Left, Right, Both or No sidebar - overridable per page and post
  • Blog widgets: Categories, Top Stories, Tags and Banner
  • Single post: share buttons, author box, post navigation and related posts
  • Guided demo import (content, images, Customizer and widgets)
  • Fully responsive layout
  • Translation ready - includes a .pot file
  • 100% GPL - clean, commented code

Heliolisk is a single-page portfolio theme for professionals who want to present their work, experience and results in one clear, fast website. The home page is assembled from Heliolisk Elementor widgets, while the theme provides the header, footer, blog, archives, search, single posts, pages and 404 page.

It is a good fit for business analysts, operations and product people, consultants, marketers, developers, designers and freelancers - anyone who needs a portfolio that looks sharp on every screen.

Elementor widgets included

  • Header
  • Hero
  • About
  • What I Do
  • Projects (list and card grid, powered by the Projects post type)
  • Experience (roles, education, certifications)
  • By The Numbers
  • Skills
  • How I Work
  • Blog
  • Collaborators
  • Contact CTA
  • Footer

What is in the package

  • theme/heliolisk.zip - the theme
  • plugins/heliolisk-core.zip - the companion plugin (post types and Elementor widgets)
  • demo-data/ - demo content, Customizer settings and widgets
  • documentation/ - offline documentation
  • licensing/ - licenses and credits

Required and recommended plugins

  • Required: Heliolisk (companion), Elementor, Codestar Framework
  • Recommended: Classic Editor, Classic Widgets, CMB2, Pure Metafields, Customizer Export/Import, Widget Importer & Exporter

The theme installs and activates them for you from Appearance → Install Plugins.

Requirements

  • WordPress 5.8 or newer (tested up to 7.1)
  • PHP 7.4 or newer
